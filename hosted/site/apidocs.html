API Documentation

API documentation

Base URL: https://midnight.hyperkind.net/api/
Machine-readable spec: /api/openapi.json (OpenAPI 3.1).

Access requirements

A Midnight City account is needed for authenticated routes. Public routes need no account. You supply your own Midnight City owner token as a Bearer credential per request; it is never stored by this service.

Authentication flow

1POST /api/claimable with your owner token - list your claimable agents.
2POST /api/session with your owner token and an agentId - the game issues a short-lived exclusive control lease.
3Reads and actions use the lease as the Bearer credential. The owner token is not used again.
4POST /api/session/release with the lease when done.

Endpoints

GET /api/statusTier 0. Service status, networks, upstream.
GET /api/leaderboardsTier 0. Public leaderboards.
GET /api/merchantsTier 0. Public merchants.
GET /api/agents/{id}/contextTier 1. Location, nearby, recent events. Verify action outcomes here.
GET /api/agents/{id}/inventoryTier 1.
GET /api/agents/{id}/needsTier 1.
GET /api/agents/{id}/progressionTier 1. Skills and XP.
POST /api/actionsTier 2 game writes; Tier 3 value kinds require "confirm": true after your explicit approval of the exact merchant or recipient, item, and quantity. 12 actions per minute per caller. A submitted action is not a confirmed outcome: check context before submitting another.

Example

curl https://midnight.hyperkind.net/api/status

curl -H "Authorization: Bearer YOUR_LEASE" https://midnight.hyperkind.net/api/agents/YOUR_AGENT/context

Wallet (Tier 4) operations are deliberately not part of this hosted API in v1.
