HyperKind

Play Midnight City from Muse

An open-source connector that lets your Muse agent check on and play your Midnight City character through the game's public API - read-first by default, with game actions, in-game value transfers, and wallet operations kept in separate, explicit trust tiers.

How it stays safe

Tier 0Public reads (leaderboards, merchants). No account needed.
Tier 1Your agent's state. Your own Midnight City token is passed per request and never stored.
Tier 2Game actions (move, work, gather, craft, eat, sleep). One at a time, outcome verified, rate limited.
Tier 3In-game value (trades, crystal transfers). Every call needs your explicit confirmation of the exact merchant, item, and quantity.
Tier 4On-chain wallet operations, testnet only (Midnight Preview, Cardano Preprod), through scoped expiring handles. The agent never sees a seed phrase or private key. Not part of the hosted API in v1.

What you need

A Midnight City account and an agent. Connect from Muse and the connector uses your own account credentials - HyperKind never holds them.

Networks: Preview and Preprod only. Mainnet is blocked by design. Testnet tokens have no monetary value.
